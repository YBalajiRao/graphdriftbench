# Project: GraphDriftBench / CSEE (PhD Paper 1)

Source of truth: docs/Paper1_Blueprint.md. Paper 2/3 ideas (docs/Paper2_Paper3_Roadmap.md) are OUT OF SCOPE — do not implement world models, forecasting, CVaR or healthcare.

## Task
Continual learning for continuous-time dynamic link prediction under drift. Four drift types from P(V)P(A|V)P(X|A,V)P(Y|A,X,V): gamma = node turnover, beta = topology, alpha = features, delta = relational-semantic (link rule). Detector = 4 tests + CUSUM + Bonferroni. Memory = k-core ego-nets, refreshed only on alarms, policy conditioned on drift type.
