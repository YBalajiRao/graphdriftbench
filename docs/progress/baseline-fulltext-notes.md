| ER-GNN, Zhou & Cao, AAAI 2021, 10.1609/aaai.v35i5.16602, *Overcoming Catastrophic Forgetting in Graph Neural Networks with Experience Replay* | yes | **yes** (AAAI open PDF, 9 pages, text extracted with `pypdf` 6.21.3) | Setting: continual graph learning as **task-incremental node classification** (Cora, Citeseer: 3 tasks of 2-way classification; Reddit: 8 tasks of 5-way), "each task is a new task since classes in different tasks are entirely different". Algorithm 1: for each task $T_i$, train on $D^{tr}_i$ together with experience nodes $B$ from the buffer, then select $e$ nodes per class from $D^{tr}_i$ and add them to $B$. Three selection schemes: **Mean of Feature (MF)** – nodes closest to the class prototype (mean feature vector); **Coverage Maximization (CM)** – approximate a uniform distribution over the attribute/embedding space; **Influence Maximization (IM)** – influence-function based selection. Requires task boundaries and class labels per task. Consequence for us: an "ER-GNN-style" baseline must replace "nodes per class per task" with a rule over events/ego-nets of a single stream with no task ids (MF → events closest to a running prototype of the edge marks, CM → coverage over mark/embedding space, IM → influence scores are expensive and need a differentiable objective; recommended to implement MF and CM and document IM as not ported unless affordable). It is therefore an adaptation, not a reproduction. Details of the experience-replay loss (how replayed nodes are weighted) were not extracted in detail; re-read §Method before implementing. |
